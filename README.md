## Что делаем

- **Лендинги** — продающие страницы с формами, анимациями, мобильной версией
- **Корпоративные сайты** — многостраничные, с CMS, SEO-оптимизацией
- **Интернет-магазины** — каталог, корзина, оплата, личный кабинет
- **Веб-приложения и MVP** — авторизация, БД, бизнес-логика, API
- **Доработка и редизайн** — переделаем, ускорим, улучшим чужой проект
- **Fullstack под ключ** — от архитектуры до деплоя
